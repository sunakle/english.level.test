# English Level Test

Тест уровня английского по шкале CEFR (A1–C2): грамматика, лексика, чтение, аудирование (озвучка через браузер).

Сайт: https://sunakle.github.io/english.level.test/

## Режимы
- **Полный тест** — 76 заданий, ~30–35 минут.
- **Экспресс-тест** — 33 задания, ~10–15 минут.

Банк — 122 задания с темами. Каждая попытка собирается случайно: по нескольку вопросов каждого уровня в каждом разделе и по одному тексту каждой сложности.

## Оценка
Уровень считается по модели IRT (3-параметрическая логистическая модель): учитываются сложность вопроса и вероятность угадывания, ответ «Не знаю» оценивается отдельно. По итоговой способности рассчитываются:
- уровень CEFR с «+» и прогрессом до следующего уровня;
- балл 0–100 и доверительный интервал (надёжность оценки);
- Cambridge English Scale, примерные IELTS и TOEFL iBT, подходящий экзамен Cambridge;
- примерный словарный запас;
- уровень по каждому навыку, результат по темам и уровням сложности;
- стабильность ответов (согласованность с уровнем), темп;
- готовность к целям (путешествия, работа, учёба, фильмы без субтитров…);
- изменение по сравнению с прошлой попыткой, разбор ошибок с объяснениями.

## Иврит
Раздел изучения иврита (`hebrew.html`) с карточками в стиле Anki: колоды «Алфавит», «Огласовки», «Слова», «Фразы» и свои карточки. Интервальные повторения по алгоритму SM-2 (шаги 1 и 10 минут, кнопки «Снова / Трудно / Хорошо / Легко»), таблица алфавита с конечными формами и правилами чтения, список карточек и статистика. Прогресс хранится в браузере.

## SUNAKLE
Персональный раздел тренировки (`sunakle.html`) по результату теста B1+: план на 12 недель до B2, 10 уроков с упражнениями по слабым темам, 109 слов с карточками (интервальные повторения), работа над ошибками теста и подборка сериалов, фильмов, аккаунтов в X, статей и книг. Прогресс хранится в браузере.

## Файлы
- `sunakle.html`, `sunakle.js`, `sunakle-data.js` — раздел SUNAKLE (данные — в `sunakle-data.js`)
- `hebrew.html`, `hebrew.js`, `hebrew-data.js` — раздел иврита (колоды — в `hebrew-data.js`)
- `index.html` — страница
- `style.css` — стили
- `app.js` — логика теста и подсчёт результата
- `questions.js` — банк вопросов и список тем (правильный ответ — первый вариант, при показе варианты перемешиваются)
