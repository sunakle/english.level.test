# English Level Test

Тест уровня английского по шкале CEFR (A1–C2): 58 заданий в четырёх разделах — грамматика, лексика, чтение, аудирование (озвучка через браузер).

После теста показывается:
- уровень CEFR (с «+», если следующий уровень освоен частично);
- общий балл 0–100 с учётом сложности вопросов;
- примерное соответствие IELTS и TOEFL iBT, оценка по 5-балльной шкале;
- уровень и процент по каждому навыку и по каждому уровню сложности;
- сильные и слабые стороны, рекомендации;
- разбор ошибок с объяснениями.

Прогресс и история попыток сохраняются в браузере.

## Файлы
- `index.html` — страница
- `style.css` — стили
- `app.js` — логика теста и подсчёт результата
- `questions.js` — банк вопросов (правильный ответ — первый вариант, при показе варианты перемешиваются)
